# Official API & Tool Links

These are the official references for the APIs, libraries, and tools used in the project.

| API / Tool | Free Eligibility | Official Link | Usage in Project |
|---|---|---|---|
| Google Gemini API | Free tier with usage limits | https://aistudio.google.com/ | Generative AI for ideas, analysis, chatbot, and reports |
| Google Trends | Free, no API key | https://trends.google.com/trends/ | Market trend and keyword popularity reference |
| PyTrends | Free open source | https://github.com/GeneralMills/pytrends | Connects Python tooling to Google Trends data |
| DuckDuckGo Search | Free | https://duckduckgo.com/ | Competitor research and web retrieval |
| ddgs / DuckDuckGo Search Python Library | Free open source | https://pypi.org/project/ddgs/ | Python search integration |
| NewsAPI | Free developer plan with limits | https://newsapi.org/ | Startup industry news and market signals |
| LangChain | Free open source | https://docs.langchain.com/ | Tool wrappers, RAG support, and agent workflow foundation |
| ChromaDB | Free open source | https://docs.trychroma.com/ | Persistent vector database for knowledge retrieval |
| Sentence Transformers | Free open source | https://www.sbert.net/ | Optional transformer embeddings for RAG |
| BeautifulSoup4 | Free open source | https://www.crummy.com/software/BeautifulSoup/bs4/doc/ | Web page title and summary extraction |
| ReportLab | Free open-source toolkit available | https://docs.reportlab.com/ | PDF report generation |

## Required API Keys

- `GEMINI_API_KEY`: create from Google AI Studio.
- `NEWS_API_KEY`: create from the NewsAPI developer dashboard.

## No API Key Required

- Google Trends through PyTrends
- DuckDuckGo Search through `ddgs`
- BeautifulSoup4
- ChromaDB local storage
- LangChain
- Sentence Transformers local model
- ReportLab
